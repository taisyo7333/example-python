# example-python


## Flask
This is an example application to say hello world using Flask.

### Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### Run

```bash
python3 main.py
```

You will see "Hello World" on your browser when accessing to http://0.0.0.0:5000/
